# Darba rīku portāls — Google Material Design 3 & Android UX

Visas lapas ir pārveidotas vienotā **Google Material Design 3 (M3)** dizaina sistēmā un optimizētas lietošanai uz **Android viedtālruņiem** un datoriem:

## Failu saraksts
- `index.html` — Portāla sākumlapa ar navigācijas kartītēm un gaišā/tumšā režīma pārslēgu.
- `atskaites.html` — Pārdošanas atskaišu veidotājs (Excel) un masveida A4 izdrukas/PDF rīks.
- `rekini.html` — Pilnais PDF rēķinu automātiskais korektors (ar iebūvētiem latviešu fontiem, svītrkoda/saņēmēja dzēšanu, līguma nr. pievienošanu un tabulas izlīdzināšanu).
- `m3-theme.css` — Vienotais Material Design 3 stila kodols (48dp skārienmērķi, `100dvh` mobilais izkārtojums, Light/Dark režīms, M3 Snackbar).
- `manifest.json` — PWA konfigurācija, lai Android Chrome pārlūkā portālu varētu pievienot telefona sākuma ekrānam (*Add to Home Screen*) kā pilnvērtīgu aplikāciju.
